MNIST Digit Classification with CNN
This project builds a Convolutional Neural Network (CNN) using TensorFlow/Keras to classify handwritten digits from the MNIST dataset.

 Features
Loads and preprocesses mnist_train.csv and mnist_test.csv.

Normalizes and reshapes data for CNN input.

Trains a CNN model on digit images (0–9).

Evaluates performance with accuracy, a confusion matrix, and a classification report.

 Requirements

numpy

tensorflow

scikit-learn
